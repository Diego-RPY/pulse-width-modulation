* The PWM module is composed of two 74161 counters and two 7485 comparators which together form a 5 bit PWM capable of producing 32 distinct duty cycles. Due to the architecture used in the state machine 5 of the 32 duty cycles are only ever used. The corresponding signals associated with the different states are specified in three tables in the README.md file under the state-machine folder.

* The way the PWM module works is through two distinct signals, the counter signal, and the control signal. The counter signal is generated by the counters, which by the cascaded composition of the two counters is able to generate a signal of up to 5 bits. The control signal originates from the state machine and it is 5 bits long. When the system begins working the counter signal starts at 0 and depending on which end of the comparator is tied to be the output signal it will output a high value for the duration of the duty cycle that the system will be in.

* The counters are tied to the ground in order to start the count from 0, and as observed in the diagram only 5 of the total of 8 possible outputs of the counter are used. This is due to the nature of a 5-bit PWM which only needs a 5 bit signal from both the counter and the control value.
